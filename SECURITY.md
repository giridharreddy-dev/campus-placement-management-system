# Configuration and public demo scope

This repository is a local portfolio demonstration. Configure local secrets in ignored .env files; never commit real passwords, database dumps, personal student records or access tokens. .env.example files contain placeholders only. The Angular sample password is intentionally public and differs from the source installation. Do not expose seeded demo accounts as a production service.

React's browser-only /demo uses fictional localStorage data. The authenticated React and Angular portals require their own API/database configuration. Uploaded source is a new sanitized snapshot; previous local Git history is excluded.
